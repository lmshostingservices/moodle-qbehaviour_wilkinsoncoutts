# qbehaviour_wilkinsoncoutts

## Summary

Provide a Moodle quiz question behaviour with controlled progression, answer review, and final submission confirmation.

## Description

A Moodle quiz question behaviour that prompts students to answer before moving forward, supports reviewing answers through quiz navigation, persists answers during navigation, and warns that submitted questions and feedback will no longer be viewable after the attempt is closed.

## Features

- Answer-required progression
- Answer review through quiz navigation
- Final submission confirmation

## Requirements

- Moodle 4.3 or 4.4

## Current Release

Version 3.2 republishes the reviewed authoritative source under a new immutable tag because the historical tag contained a different source tree. There are no functional changes in this release.
